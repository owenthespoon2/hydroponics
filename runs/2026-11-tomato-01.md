# Run 1: Premium Ruby tomato

First hydroponic run, started **2026-11-19**. A passive Kratky jar: a sponge holds the seed over a nutrient reservoir, with no pump and no electricity beyond the lamp.

## Why tomato, not basil
The basil seed packet was mouldy when opened, so it was not used. The tomato seeds looked fine, so tomato went first.

## What this run is for
- Learn the basics of a Kratky jar end to end: sprouting in the sponge, reservoir level, roots, light.
- Learn what winter temperature does to it, which leads into the heater project (see [docs/heating-project.md](../docs/heating-project.md)).
- It is a first attempt. If it fails, the log of why is still the result.

## Known constraints (stated up front so the log stays honest)
- **1.3 L is small for this variety.** Premium Ruby is a greenhouse-type cherry tomato (fruit about 15–20 g, grown in trusses). The seller's page does not state plant height or habit, but this type of tomato normally keeps growing tall. Expect to move it to a much larger reservoir if it thrives. The jar is a seedling-stage container.
- **Cold.** It is November in Niigata. Seeds germinate best warm, so root temperature matters from day 0.
- **Away from 2026-12-14 for about 3 weeks** (trip to England). The plant will be about 3.5 weeks old when that starts. The heater and thermostat should be proven before then.
